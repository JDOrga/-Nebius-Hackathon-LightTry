# 当前架构与目录边界

## 正式本地调用链

`start.py → project/studio.py → shared_http.Handler / SchemeStore`

前端仅 `project/web/`。`language.py` 是文字服务基础协议与预算适配，`recipe_language.py` 校验方案与上下文；并非两套产品。`inference/` 提供任务持久化、照片校验、逆过程缓存、共享打包/提取与守护授权检查；`runtime/` 提供参数化条件、单方案和联合实验适配。共享 driver helper 只维护一份，旧固定预设与参数化传输策略仍分别保留，不削弱任何收费/时间/哈希/主机保护。

## 数据与历史

本机路径只在 `.local/studio.json`；稳定任务、素材、环境库、逆过程缓存位于 `.local/state/`。不硬编码带日期的本机目录，不以工作目录猜素材。历史冻结包只读保留其原字节、清单和路径；读取器兼容旧 `project/next/runtime/` 布局，新包使用 `project/runtime/`。旧包的源码哈希与已关闭授权不自动迁移或复用。

现有 Python 虚拟环境不搬迁（venv 含机器路径）；配置显式指向已安装环境，不自动安装或下载。已验收的结果包和实验图可以从历史目录只读导入，但必须通过原始来源、SHA 与身份校验，不冒充本轮生成。

## 非产品目录

`cloud/` 是显式云调度/安全收尾；`scripts/` 是准备、审计、实验执行工具；`prototype/` 是正式推理仍使用的 HDR 采样适配与数学参考。`patches/`、`manifests/`、`third_party/` 是固定上游/权重/许可来源，不按“原型”名称删除。

历史文档统一在 `docs/history/`；本地原始云运行、账本、素材、任务和失败证据保留原处，不批量搬动已有绝对路径。该边界是明确的保留策略，不代表所有历史文件仍可执行。

## 能力边界

Cosmos 是有限保真度的 AI 光照预览，不保证物理正确、文字/纹理/材质不变。Nemotron 仅给文字方案，不自动应用、生成或启动云机。普通启动关闭文字与 GPU；交互确认、预算、守护、单次启动/launch、600秒启动上限及停机四项核验仍按执行规范，结构整理不代表新增实机验证。
